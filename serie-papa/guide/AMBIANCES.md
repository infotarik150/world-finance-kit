# Les ambiances par genre

À choisir **avant** d'écrire les plans. Une vidéo peut mélanger deux ambiances (ex. psycho + funny), mais une seule domine.
Les personnages listés sont des suggestions : on choisit toujours en fonction du scénario.

## Scary / suspense (référence : vidéo 03 « Mom on the phone »)

| Élément | Choix |
|---|---|
| Personnages | Ceux de la famille en danger : Sophie, Luna, Léo, Papa, Max (chien qui sent quelque chose) |
| Fonds | Bleu nuit presque noir `#0B1020`, violet profond `#2A1846`. **Jamais d'orange vif.** Une seule source de lumière chaude (hotte, lampe, porte entrouverte) |
| Décor au trait | Blanc **atténué** (≈ 50 % d'opacité), pour que le noir domine |
| Angles | Contre-plongée au ras du sol (le personnage devient menaçant), vue subjective (on est à la place de la victime), plongée vertigineuse (escalier), plan penché, cadrage décentré, personnage vu de dos qui « ne se retourne pas » |
| Mouvements | Lents : approche très lente, effet vertige (on avance en dézoomant), image figée au moment clé |
| Étalonnage (montage) | Désaturé, contraste un peu plus fort, vignettage, léger grain, lumière qui vacille de temps en temps |
| Sons | Bourdonnement grave (`drone.wav`) qui monte aux moments clés, battements de cœur (`coeur.wav`), **silence brutal** quand un son s'arrête (la poêle), vibration de téléphone, impact final |
| Sous-titres | Blanc, **mots clés en rouge** `#FF3B3B` |
| Icônes | Rares et discrètes (lune, cadenas) |
| Narrateur | Calme, grave, posé (Frank) |
| Fin | Question au public + fondu au noir |

## Business / argent / carrière

| Élément | Choix |
|---|---|
| Personnages | Alex, Victoria, Papa (le budget de la famille), ROBI (l'outil, les chiffres) |
| Fonds | Bleu nuit `#1F2A4F`, crème `#F3EADB`, vert pistache pour le gain, touches dorées |
| Angles | Plan moyen face caméra (confiance), légère contre-plongée sur celui qui a le pouvoir, champ / contre-champ dans une négociation, gros plan sur un chiffre ou un geste |
| Mouvements | Nets et posés, travelling latéral, zoom sur le chiffre clé |
| Icônes | Pièces, flèche qui monte / descend, graphique, horloge, poignée de main, cadenas |
| Sons | Pop des icônes, clic, « ka-ching » discret pour un gain |
| Sous-titres | Blanc sur foncé, brun `#2A1A10` sur crème ; mots clés en **doré** |
| Narrateur | Professionnel et chaleureux (Terence, Morgan) |

## Sport / motivation (référence : vidéo 01 « Devenir sportif »)

| Élément | Choix |
|---|---|
| Personnages | Le Sportif, Papa (le débutant), Léo, Max (court avec eux) |
| Fonds | Couleurs vives : orange, bleu ciel, vert pistache, jaune |
| Angles | Contre-plongée héroïque, plans dynamiques, caméra qui suit la course, zoom rapide sur le muscle / le chrono |
| Mouvements | Rapides, orbite autour du personnage, changements de fond en cercle |
| Icônes | Flèche qui monte, horloge, calendrier coché, cœur, médaille |
| Sons | Pas de course (avec parcimonie), whoosh aux changements de scène, wouf de Max |
| Narrateur / voix | Énergique (Knox) |

## Funny / humour

| Élément | Choix |
|---|---|
| Personnages | Papa (maladroit), Léo, Max, ROBI (qui comprend tout de travers), Luna (sarcastique) |
| Fonds | Couleurs vives et changeantes : jaune, rose, bleu ciel, orange |
| Angles | Plans larges pour le gag, **gros plan soudain sur la réaction**, zoom « choc » rapide, plongée sur le personnage qui se fait avoir |
| Mouvements | Timing comique : pause avant la chute, zoom rapide, image figée sur la grimace |
| Icônes | Point d'exclamation, goutte de sueur, ampoule, étoiles |
| Sons | Boing, pop, impact cartoon, silence avant la chute |
| Sous-titres | Mots clés en jaune ou en couleur vive |

## Psycho / comportement humain (référence : vidéo 02 « The Chair Test »)

| Élément | Choix |
|---|---|
| Personnages | Dr. Gabriel (l'explication), plusieurs personnages pour comparer les comportements |
| Fonds | Bleu nuit, violet, crème pour l'explication |
| Angles | Observation : plan large fixe comme une caméra cachée, puis gros plan sur le détail qui trahit (le geste, l'objet) ; le psy en plan moyen avec un léger zoom pendant l'explication |
| Mouvements | Calmes, zoom lent, comparaison côte à côte |
| Icônes | Croix / coche, œil barré (« personne ne regarde »), point d'interrogation, ampoule |
| Sons | Discrets : impact grave au début, scan, petite note quand l'idée tombe |
| Mise en évidence | La différence doit se voir tout de suite : grand écart, repère au sol en pointillés, croix / coche |
| Narrateur | Calme et mystérieux (Frank) ou le psy (Christian) |

## Rappel des personnages

| Personnage | Utile pour |
|---|---|
| Papa | Le quotidien, l'argent de la famille, l'adulte qui se pose des questions |
| Le Sportif | Sport, motivation, discipline |
| Sophie (maman) | Famille, éducation, peut devenir inquiétante (scary) |
| Alex | Business, argent, stratégie |
| Victoria | Leadership, négociation |
| Dr. Gabriel | Psychologie, explications |
| Luna | Ado, réseaux sociaux, victime ou héroïne d'histoire scary |
| Léo | Enfance, énergie, humour |
| Adam | Tech, jeux vidéo |
| ROBI | IA, explications, humour décalé |
| Max | Émotion, humour, ou « il sent quelque chose » en scary |
